# agent-browser

Браузер под управлением агента: открыть страницу, кликнуть, заполнить форму,
залогиниться, снять скриншот, вытащить данные, проверить своё веб-приложение.

## Качать нужно два уровня

Это важно понять до установки, иначе скилл «не работает».

```
┌─────────────────────────────────────────────┐
│  наш слой  — этот скилл (SKILL.md)          │  когда звать, каким циклом
│            методика, грабли, ограничения    │  работать, что запрещено
├─────────────────────────────────────────────┤
│  движок    — CLI `agent-browser`            │  сам умеет открывать,
│            нативный бинарь, Apache-2.0      │  кликать, снимать слепки
├─────────────────────────────────────────────┤
│  браузер   — Chrome / Chromium              │  то, что реально рисует
│            управляется по CDP               │  страницу
└─────────────────────────────────────────────┘
```

**Скилл сам по себе ничего не открывает.** Он объясняет агенту, как пользоваться
движком. Без установленного движка команды из скилла вернут «command not found».

## Установка движка

Один из трёх способов — что удобнее:

```bash
# npm
npm install -g agent-browser

# Homebrew (macOS)
brew install agent-browser

# Cargo (Rust)
cargo install agent-browser
```

Затем один раз скачать браузер:

```bash
agent-browser install          # тянет Chrome for Testing -- официальную сборку Google под автоматизацию
```

На Linux дополнительно нужны системные библиотеки браузера:

```bash
agent-browser install --with-deps
```

Проверка, что всё встало:

```bash
agent-browser --version
agent-browser open https://example.com && agent-browser snapshot -i
agent-browser close
```

Обновление: `agent-browser upgrade` — сам определит, чем ставили (npm, brew,
cargo), и обновится соответствующим способом.

## Требования к окружению

| Что | Зачем | Комментарий |
|---|---|---|
| macOS, Linux или Windows | движок — нативный бинарь | сборки под arm64 и x64 идут в пакете |
| Node.js + npm | только если ставишь через npm | сам движок при работе Node не требует, это нативный бинарь |
| Rust | только для установки через `cargo` | не нужен при npm и brew |
| Chrome / Chromium | то, чем реально рулит движок | ставится командой `agent-browser install`, сотни МБ на диск |
| Системные библиотеки браузера | Linux и контейнеры | `agent-browser install --with-deps` |
| Xcode + Appium | только для режима iOS-симулятора | опционально, для мобильного Safari |

API-ключей и подписок движок не требует: он гоняет локальный браузер. Ключ нужен
только для необязательных вещей — чат-вкладки в наблюдательной панели и облачных
провайдеров браузера.

## Playwright и agent-browser

Частая путаница, поэтому прямо:

**Движок под этим скиллом — не Playwright.** `agent-browser` — самостоятельный
нативный CLI, который разговаривает с Chrome напрямую по CDP (Chrome DevTools
Protocol). Апстрим формулирует это так: для работы демона Playwright не нужен.

**Playwright** (Microsoft, <https://playwright.dev>, исходники
<https://github.com/microsoft/playwright>) — отдельный, тоже отличный фреймворк
автоматизации браузера. Пересечение с ним ровно одно, практическое: если
Playwright у тебя уже установлен, `agent-browser` найдёт и переиспользует
скачанный им Chromium — тогда шаг `agent-browser install` можно пропустить. То же
верно для установленных Chrome, Brave и Puppeteer.

Как выбрать:

| Задача | Инструмент |
|---|---|
| Агент управляет браузером командами, по шагам, с разбором страницы | `agent-browser` (этот скилл) |
| Ты пишешь код автотестов на TypeScript или Python, гоняешь в CI | Playwright |
| Нужен headless-рендер HTML в картинку внутри своего скрипта | Playwright |

Оба варианта в итоге управляют Chromium — разница в том, кто пишет сценарий:
агент по ходу дела или разработчик заранее.

## Установка скилла

```bash
npx skills add github.com/qwwiwi/agentos-skills-public --skill agent-browser
```

Или скопировать папку в `~/.claude/skills/`.

## Быстрая проверка, что связка работает

```bash
agent-browser open https://example.com
agent-browser snapshot -i         # должен вывести элементы с метками @e1, @e2...
agent-browser screenshot          # путь к PNG в выводе
agent-browser close
```

Если `snapshot -i` пустой, а `screenshot` белый — страница ещё грузится: добавь
`agent-browser wait 2000` перед слепком.

## Ограничения

Скилл без движка не работает. Капчу и антибот-защиту не обходит и не должен.
Сайты, которые блокируют автоматизацию, останутся заблокированными — это не
чинится подбором user-agent. Файлы сохранённых сессий содержат живые токены и
требуют обращения как с паролями. Полный разбор — в `SKILL.md`, раздел
«Ограничения».
