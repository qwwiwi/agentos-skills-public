# reel-radar

Контент-разведка Instagram под съёмку. Берёт эталонный аккаунт твоей ниши,
сканирует его подписки, находит залетевшие рилсы за неделю и отдаёт дашборд с
25 референсами плюс 15 готовых ТЗ на съёмку.

Отвечает на один вопрос: **что снимать на этой неделе**. Отбор финальных 15
делается не по абсолютным просмотрам, а по совпадению с тем, что уже работает на
твоём собственном аккаунте.

## Установка

```bash
npx skills add github.com/qwwiwi/agentos-skills-public --skill reel-radar
```

Или скопировать папку в `~/.claude/skills/`.

## Что нужно

| Что | Зачем | Где взять |
|---|---|---|
| Python 3.9+ | скрипты, только стандартная библиотека | https://python.org |
| FFmpeg | сжатие видео и извлечение аудио | https://ffmpeg.org |
| `HIKER_KEY` | данные Instagram | https://hikerapi.com |
| `GROQ_KEY` | транскрипция | https://console.groq.com |
| `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` | доставка артефактов, опционально | @BotFather |

```bash
export HIKER_KEY="..."
export GROQ_KEY="..."
export TARGET_USER="your_account"   # эталонный аккаунт ниши, без @
```

Ключи только через переменные окружения. В репозитории нет ни ключей, ни
аккаунтов, ни chat_id — без настройки скрипты падают с понятной ошибкой.

## Быстрый старт

```bash
# 1. заполни ключевые слова своей ниши
$EDITOR config/keywords.txt

# 2. прогон без доставки в Telegram — артефакты лягут в /tmp/reel-radar/<дата>
bash scripts/run.sh --skip-telegram

# 3. упал на середине — продолжить с последнего шага
bash scripts/run.sh --resume --skip-telegram

# 4. расширить пул аккаунтов ниши (отдельно от основного пайплайна)
python3 scripts/find-creators.py /tmp/creators --target 100 --min-followers 10000
```

## Структура

```
SKILL.md                      полный метод: пайплайн, правило 1-в-1, ограничения
config/defaults.json          окна, пороги, размеры выборок, эталонный аккаунт
config/keywords.txt           словарь ниши, по одному слову на строку
data/watchlist.example.json   пример запасного списка аккаунтов
scripts/run.sh                оркестратор 11 шагов с resume
scripts/_config.py            разрешение аккаунта и ключей: CLI > env > конфиг
scripts/1..8                  сбор, фильтр, ранжирование, транскрипция, матч
scripts/9-gen-dashboard.py    HTML-дашборд с 25 референсами
scripts/10-gen-tz.py          15 ТЗ на съёмку
scripts/11-deliver-telegram.sh доставка артефактов в Telegram (опционально)
scripts/find-creators.py      поиск новых аккаунтов ниши по ключам и хэштегам
scripts/validate-fidelity.py  проверка ТЗ на соответствие оригиналу 1-в-1
templates/                    HTML-шаблоны дашборда и ТЗ
```

## Перенос на другую нишу

Заменить `config/keywords.txt`, эталонный аккаунт в `TARGET_USER` и списки
`KEYWORDS` / `HASHTAGS` / `TOPIC_TERMS` в `scripts/find-creators.py`. Код ниши не
знает. Код-слова CTA — через `CODE_WORDS_FILE`, дизайн — через `templates/`.

## Ограничения

Без `HIKER_KEY` не работает ничего, без `GROQ_KEY` не будет транскриптов, а
значит ТЗ выйдут пустыми болванками. Доступ к данным Instagram неофициальный:
сервис сторонний, формы ответов меняются, закрытые аккаунты не отдают подписки.
Досматриваемость, охваты и сохранения снаружи недоступны в принципе. Скилл
только читает публичное и ничего не публикует, но само использование
неофициального доступа противоречит ToS Instagram — не подставляй сюда аккаунт,
который жалко потерять. Полный разбор — в `SKILL.md`.
