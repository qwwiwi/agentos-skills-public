# reels-analytics-for-brokers

Радар восходящих рекламных офферов в Instagram. Демонстрационный образец: ниша —
брокеры и риелторы, но нишу знает только конфиг, не код.

Инструмент отвечает на один вопрос: **что в нише начинает набирать силу прямо
сейчас**. Оффер живёт три-четыре недели, поэтому разовый разбор бесполезен —
нужен регулярный срез, который сравнивает себя с предыдущим.

## Правило номер ноль

**Первую сотню конкурентов ты собираешь руками, не агентом.** Ручной проход по
ленте рекомендаций даёт то, что не достаётся фильтром: понимание, кто в этой
нише вообще считается конкурентом и какие форматы тут живут. Автоматизировать
можно только то, что ты уже сделал руками хотя бы раз. Подробно — в `SKILL.md`.

## Установка

```bash
npx skills add github.com/qwwiwi/agentos-skills-public --skill reels-analytics-for-brokers
```

Или скопировать папку в `~/.claude/skills/`.

## Что нужно

| Что | Зачем | Где взять |
|---|---|---|
| Python 3.9+ | скрипты, только стандартная библиотека | https://python.org |
| FFmpeg | раскадровка и извлечение аудио | https://ffmpeg.org |
| `HIKER_API_KEY` | данные Instagram | https://hikerapi.com |
| `GROQ_API_KEY` | транскрипция (опционально) | https://console.groq.com |

```bash
export HIKER_API_KEY="..."
export GROQ_API_KEY="..."
```

Ключи только через переменные окружения.

## Быстрый старт

```bash
# 0. собери manual-100.txt руками — см. правило номер ноль

# 1. пул: ручная сотня + снежный ком по её подпискам
python3 scripts/seed_pool.py --config config/niche.brokers.json \
    --out runs/$(date +%F) --sources manual,following --seed-file manual-100.txt

# 2. квалификация: профиль, активность, медиана просмотров
python3 scripts/qualify_accounts.py --config config/niche.brokers.json --out runs/$(date +%F)

# 3. ранжирование по всплеску к собственной медиане аккаунта
python3 scripts/rank_reels.py --out runs/$(date +%F) --top 250 --days 14

# 4. разбор ролика: кадры первых 3 секунд, транскрипт, комментарии
./scripts/teardown_reel.sh REELCODE runs/$(date +%F)/teardowns

# 5. офферы и динамика к прошлому срезу
python3 scripts/offers_diff.py extract --out runs/$(date +%F)
python3 scripts/offers_diff.py diff --previous runs/ПРОШЛАЯ_ДАТА --current runs/$(date +%F)
```

## Структура

```
SKILL.md                     полный метод: правило номер ноль, пайплайн, ограничения
config/niche.brokers.json    ниша целиком: ключевые слова, хэштеги, пороги
scripts/hiker.py             клиент API: лимит запросов, ретраи, разбор ответов
scripts/seed_pool.py         сбор пула + бесплатный фильтр до платных запросов
scripts/qualify_accounts.py  профиль, активность, медиана, охват к базе
scripts/rank_reels.py        ранжирование по всплеску, а не по абсолюту
scripts/offers_diff.py       извлечение офферов и сравнение срезов
scripts/teardown_reel.sh     видео, раскадровка 0,5 с, транскрипт, комментарии
references/api.md            эндпоинты, формы ответов, грабли
references/scaling.md        расчёты на 1000 аккаунтов, партии, кэш, лимиты
references/analysis.md       как из 300 роликов вывести формулу
```

## Перенос на другую нишу

Скопируй конфиг, замени ключевые слова, хэштеги, запросы и эталонные аккаунты,
подкрути пороги. Код не трогается. И собери свою ручную сотню заново — правило
номер ноль не отменяется тем, что скрипты уже написаны.

## Ограничения

Доступ к данным неофициальный, сервис сторонний, ответы Instagram меняются.
Охваты, досматриваемость и личные сообщения недоступны в принципе — их нет ни у
кого снаружи. Собирай только публичное и только для анализа рынка; персональные
данные не собирай. Полный разбор ограничений — в `SKILL.md`.
