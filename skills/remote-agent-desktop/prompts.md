# Готовые промпты

Промпты с демо-дня AgentOS. Отправьте их агенту на своём компьютере (приложение Codex): он сам заходит на сервер по SSH, ставить Codex на сервер не нужно. Копируйте целиком.

---

## Промпт 1. Сервер с удалённым рабочим столом

```
Цель: поднять для меня сервер с удалённым рабочим столом для AI-агента. Шаги делай сам, меня спрашивай только про вход в аккаунт, оплату и подтверждения.

1. Открой в браузере https://vdsina.com/?partner=6x47zemriu8q. Если я не вошёл – попроси войти и дождись. Создай сервер: Ubuntu 24.04, минимум 2 ядра и 4 ГБ RAM, ближайший дата-центр. Оплату и данные карты ввожу я сам – остановись и скажи, когда нужно оплатить.
2. IP и пароль сервера сохрани у меня на компьютере в файл ~/agent-server/access.txt (доступ только мне). В чат пароли не выводи.
3. Создай SSH-ключ на моём компьютере, добавь его на сервер, отключи вход по паролю. Пропиши хост agent-server в ~/.ssh/config. Включи ufw (порты 22 и 3389), fail2ban и обновления.
4. Создай пользователя agent с паролем (сохрани в тот же файл). Поставь XFCE и xrdp, Google Chrome, git, Node.js LTS.
5. Поставь agent-desktop по инструкции из https://github.com/vercel-labs/agent-desktop. Включи accessibility в XFCE, Chrome запускай с флагами --password-store=basic --force-renderer-accessibility. Агент работает в живой сессии рабочего стола: попроси меня один раз войти через Windows App, потом проверь, что через SSH открываешь окно на рабочем столе.
6. Создай рабочее пространство ~/workspace: AGENTS.md (кто я, чем занимаюсь, правила: ничего не удалять без моего подтверждения, пароли и ключи не выводить), папки projects, memory, skills, git init.
7. В конце напиши, как подключиться к рабочему столу: с Mac через Windows App, с Windows через «Подключение к удалённому рабочему столу» – адрес, пользователь, где лежит пароль.
```

## Промпт 2 (по желанию). Агент Hermes в Telegram на этом же сервере

Отправьте после первого промпта, когда сервер готов.

```
Цель: по SSH на сервере agent-server поставить AI-агента Hermes, который отвечает мне в Telegram и работает 24/7.

1. Установи Hermes по официальной инструкции: https://github.com/NousResearch/hermes-agent
2. Запусти hermes setup. Модель и ключи выбираю я – спроси меня и дождись ответа. Ключи и токены в чат не выводи.
3. Подключи Telegram: попроси меня создать бота в @BotFather и вставить токен прямо в настройку Hermes. Доступ к боту – только моему Telegram.
4. Напиши SOUL.md: кто я, чем занимаюсь, как со мной общаться, правила – ничего не удалять без моего подтверждения, пароли и ключи не выводить.
5. Подключи рабочее пространство ~/workspace.
6. Запусти hermes gateway как службу, чтобы агент работал после перезагрузки.
7. Попроси меня написать боту «привет» и проверь, что он ответил.
```
